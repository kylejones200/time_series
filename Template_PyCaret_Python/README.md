# PyCaret: Low-Code Time Series Forecasting

Automated time series forecasting with minimal code using PyCaret.

## Setup

```bash
pip install -r requirements.txt
```

## Configuration

Edit `config.yaml` to customize:
- **Data**: Input file path and column names
- **Model**: Models to compare, forecast horizon, sort metric
- **Plotting**: Visualization styling
- **Output**: Plot settings

## Run

```bash
python main.py
```

## Features

- Automated model comparison
- Minimal code required
- Multiple model types

## Outputs

Forecast plots and model comparison saved to `outputs/` directory.
