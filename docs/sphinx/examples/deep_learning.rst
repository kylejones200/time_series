Deep Learning Methods
======================

Deep learning methods can capture complex patterns in time series data.

LSTM
----

Long Short-Term Memory networks for sequence modeling.

**Template:** ``LSTM_Python/``

**Use when:**
- You have long sequences (> 100 points)
- Complex patterns need to be captured
- Computational resources are available

**Requirements:**
- PyTorch or TensorFlow
- GPU recommended for large datasets

N-BEATS
-------

Neural Basis Expansion Analysis for Time Series.

**Template:** ``NBEATS_Python/``

**Use when:**
- You need interpretable deep learning
- Multiple time series to forecast
- Strong performance is required

TSAI
----

Time Series AI - Deep learning for time series.

**Template:** ``TSAI_Python/``

**Use when:**
- You want state-of-the-art deep learning
- Multiple architectures to try
- Transfer learning is beneficial

BERT for Time Series
--------------------

Transformer-based models for time series.

**Template:** ``BERT_Python/``

**Use when:**
- You have labeled time series data
- Classification or regression tasks
- Pre-trained models can help

See individual template READMEs for detailed usage and configuration.
