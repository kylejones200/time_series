# TSFresh: Time Series Feature Extraction

Automated feature extraction from time series data using TSFresh.

## Setup

```bash
pip install -r requirements.txt
```

## Configuration

Edit `config.yaml` to customize:
- **Data**: Input file path and column names
- **Model**: Number of samples, feature extraction parameters, feature selection
- **Plotting**: Visualization styling
- **Output**: Plot settings

## Run

```bash
python main.py
```

## Features

- Automatic feature extraction
- Feature selection
- Comprehensive feature set

## Outputs

Feature importance plots saved to `outputs/` directory.
